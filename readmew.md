# READMEW

This file provides a quick overview of the migration demo repository.

## Project summary

This repository demonstrates an Azure DevOps to GitHub migration scenario with a small Python sample app.

## Key files

- `app.py`: Simple Python script that prints migration-themed messages.
- `README.md`: Original project documentation.
- `readmew.md`: This lightweight companion overview.

## Run the sample app

```bash
python3 app.py
```

Expected output includes a greeting for the Azure DevOps migration demo and short migration notes.
